Questions executives ask first

Does my data go to an AI provider?

Only if the admin chooses a hosted model. With a local model, questions, schema and results stay inside your network. With a hosted model, that provider receives what the model needs to answer, under your own API key.

Which models can GBI use?

Any the admin adds: open models run locally through Ollama, or hosted ones such as Anthropic, OpenAI and Gemini. You can switch later without rebuilding anything.

Which databases does it connect to?

Oracle, SQL Server, MySQL, Databricks Unity Catalog, Snowflake and others. GBI takes the SQL dialect from the data source.

Can two people see different answers to the same question?

Yes, when their access differs. Row and column rules apply to each person, so a regional head and a finance lead see what each is allowed to see.

Do my people need to know SQL?

No. They write a question. Analysts and admins can open the SQL to check or change it.
