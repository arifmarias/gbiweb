Questions people ask first

Do I need to know SQL?

No. You write a question. Analysts and admins can open the SQL if they want to check or change it.

Which databases does it connect to?

Oracle, SQL Server, MySQL, Databricks Unity Catalog, Snowflake and others. GBI takes the SQL dialect from the data source.

Does my data go to an AI provider?

That is the admin’s choice. With a local model, questions and data stay inside your network. If the admin adds a hosted model, that provider receives what the model needs to answer.

Can two people see different answers to the same question?

Yes, when their access differs. Row and column rules apply to each person, so a regional manager and a finance lead see what each is allowed to see.
